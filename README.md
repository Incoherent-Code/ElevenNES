# ElevenNES

Hobby NES Emulator in very early stages. Written using Dotnet and MonoGame Framework. 

Currently Implimented:
* 6502 CPU Emulation
* Basic Mapper Support
* Basic PPU Emulation
* Controller Input only

Needs Implimenting:
* Smaller PPU Features (Sprite Zero-Hit, Open Bus)
* Remappable inputs
* Audio Generation
* More mapper support to run more games
* Unnoficial 6502 Instructions (Currently used to detect CPU arbitrary memory execution)
